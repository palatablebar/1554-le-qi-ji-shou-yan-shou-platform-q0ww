# 乐器寄售验收台数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `wear_grade` | 外观磨损分 | 分 | 1–10 |
| `repair_count` | 历史维修次数 | 次 | 0–8 |
| `setup_age` | 距上次校准 | 天 | 1–270 |
| `photos` | 有效细节照片 | 张 | 2–32 |
| `price_index` | 挂牌价与行情比 | % | 51–155 |
| `play_log` | 试奏留档时长 | min | 0–55 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。标签 0 为已核实正常，1 为需要复核的实绩。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 品相记录 | `wear_in_tenths` | 品相磨损十分级 | 10 | 0 |
| 品相记录 | `previous_repairs` | 返修档数 | 1 | 0 |
| 估价单 | `setup_hours_old` | 校准留档时数 | 24 | 0 |
| 估价单 | `usable_witness_photos` | 有效档案照片 | 1 | 0 |
| 试奏交接 | `asking_basis_points` | 行情倍率万分数 | 100 | 0 |
| 试奏交接 | `recorded_play_sec` | 试奏文件秒数 | 60 | 0 |

示例见 `sample_data/consignment_notes_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[1,40)`、校准 `[42,61)`、回放 `[65,83)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `wear_repairs` | 磨损和历史维修 | `wear_grade+.7*repair_count` |
| `setup_lag` | 试奏修正的校准时差 | `setup_age/(1+play_log)` |
| `photo_attestation` | 细节证据密度 | `photos/(1+wear_grade)` |
| `pricing_gap` | 挂牌价偏差 | `abs(price_index-100)` |
| `repair_risk` | 溢价时的维修负担 | `repair_count*price_index/100` |

### 分门店 Beta-Binomial 收缩

对磨损、校准延迟和照片密度建立离散格。先以全体记录平滑每格的退货率，再对各门店做二级收缩。

本工作台的独立样本校准方式为寄售全店风险借力。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较训练邻域距离。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 安排二次验收

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `MISSING_DETAIL` | `wear_grade >= 7 and photos <= 6` | 补传主要磨损位照片 |
| 2 | `SETUP_EXPIRED` | `setup_age >= 160 and play_log <= 12` | 试奏和校准留档不足 |
| 3 | `PRICE_REVIEW` | `price_index >= 128 and repair_count >= 4` | 核对翻修与行情 |

第一条为暂停规则。其余命中与模型阈值 `0.5` 共同决定是否列入候选。单据所需工位数按 `1 + int(repair_count>=5)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 琴台二验排单

按维修经历、校准龄期和有效照片估算复验分钟和补拍张数。已经分派的琴单占用本班琴台时段，挂牌价核对记录交给寄售专员签认。 在派发环节展开现场安排，或从关联单据回查实际读数。
